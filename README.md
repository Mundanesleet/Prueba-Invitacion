# Alejandro & Luisa · Invitación de boda

Invitación web (26.02.2027) hecha con HTML, CSS y JavaScript, sin dependencias. Lista para GitHub Pages.

## Ver en local
Abre `index.html` en el navegador.

## Publicar con GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save.

## Qué editar
- **Fecha/hora del contador y calendario:** `js/main.js` → objeto `CONFIG`.
- **Textos, horarios y lugares:** `index.html`.
- **Enlaces de ubicación:** en `index.html`, pon el link de Google Maps en el `href` del botón y borra `data-pending`.
- **Fotos opcionales:** ver `assets/img/LEEME.md`.
- **Vista previa en WhatsApp:** cuando el sitio esté publicado, cambia `og:image` por la URL completa y sube `assets/og-image.jpg` (1200 × 630 px).
